title: 简介
---

> 官方地址：[https://semgrep.dev](https://semgrep.dev )

Semgrep是一款**快速**、**开源**的静态代码分析工具。它采用类似代码的**简洁**语法来定义规则，让开发者能轻松查找并修复代码中的错误、漏洞和规范问题。具体来说，其优势主要有以下几点：

- **大多数语言无需构建**：Semgrep 几乎可以在任何仓库上运行，无需复杂设置。像 CodeQL 这样的工具通常需要可构建的环境，并使用自己的查询语言。
- **规则编写速度快、门槛低**：Semgrep 的模式类似真实代码，且允许定制和扩展而无需领域特定语言、管理抽象语法树或正则表达式处理，这些特点使得其学习成本低、编写和测试容易、可读性强。也就使得其规则的编写门槛相比其他SAST格外低，这使得它区别于某些很"重"、默认规则强但可定制性差的工具。
- **支持 30+ 种编程语言**：如今时代下，即使一个普通的跨端应用涉及的语言也可能超过5种，使用一个支持语言种类丰富的工具是极大的方便，几乎能针对全公司代码做统一SAST扫描，维护成本低。
